# DCinSoVITS

[한국어](README_kr.md) | [English](README_en.md) | [日本語](README_jp.md)

A native macOS app that extracts audio from a video, splits it by speaker, and builds **GPT-SoVITS (v2)** fine-tuned weights from the speaker you choose.

Made by **HolicJin**

> ⚠️ **Disclaimer / 이용 고지 / ご注意** — This repository and the app ship with **no videos, no celebrity voices, and no biometric sample data**. You are solely responsible for any media you load and for all outputs (separated audio, model weights, synthesized speech). Use only with rights and consent. Do not use another person’s voice without the rights holder’s consent.
